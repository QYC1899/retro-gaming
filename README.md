# 🕹️ 复古电脑 1977 — 20 款经典怀旧游戏机 (Retro Computer 1977)

> 一款 1970/1980 年代经典台式电脑仿真游戏平台。包含米色 CRT 监视器、台式机机箱、卡带插拔 3D 动画、复古机械键盘与 20 款可玩怀旧街机小游戏。

---

## ✨ 核心特性

### 1. 🖥️ 经典 CRT 监视器与复古机箱仿真
- **米色 ABS 塑料机箱**：还原 70 年代经典米黄色工控设计与斜切倒角边框。
- **CRT 玻璃曲面屏**：呈现绿色/琥珀色磷光发光管、扫描线（Scanlines）、右上角球面玻璃反光高光及开机消磁闪烁效果。
- **交互式控制旋钮与指示灯**：
  - **BRIGHT** 亮度旋钮：实时调节 CRT 显示屏明暗。
  - **POWER LED** 绿色电源指示灯与微动电源开关。
  - **DRIVE ACT** 驱动器读写琥珀色闪烁指示灯。
  - **EJECT** 机械弹簧退卡按键。

### 2. 🗃️ 左右双翼卡带陈列架与 3D 插入动画
- **左右双侧机架**：
  - **左侧机架 A（VOL.01 ~ VOL.10）**
  - **右侧机架 B（VOL.11 ~ VOL.20）**
- **拟真 3D 插卡动画**：点击任意卡带，卡带从侧边机架升起、空中对准中央驱动器插槽并平滑滑入，机箱读卡灯闪烁，CRT 屏幕启动 BIOS 引导加载并进入游戏。
- **出卡清屏功能**：按下 **EJECT** 机械出卡，卡带弹出归位，显示器即刻清屏并恢复经典命令行待机状态。

### 3. ⌨️ 拟真两段式机械键盘
- **双色复古键帽**：米白色字母按键与深灰色功能修饰键。
- **全键盘物理/虚拟联动**：在实体键盘敲击或用鼠标点击屏幕键帽，均触发键帽下沉反馈与机械轴体清脆微动音效。

### 4. 🔊 Web Audio 原生合成音效
- 无需下载任何音频文件，利用 Web Audio API 纯代码合成：
  - 机械轴体敲击声 (`playKeyClick`)
  - 重型塑料卡带入槽与弹簧卡扣声 (`playCartridgeInsert` / `playCartridgeEject`)
  - CRT 显像管高压消磁嗡鸣声 (`playCrtDegauss`)
  - 8-bit 复古电子蜂鸣提示音 (`playBeep`)
  - 顶部一键静音/解除静音控制

## 🛠️ 技术栈

- **前端框架**：[React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **路由与全栈架构**：[TanStack Router / Start](https://tanstack.com/router)
- **样式系统**：[Tailwind CSS v4](https://tailwindcss.com/)
- **构建工具**：[Vite](https://vitejs.dev/) / [Bun](https://bun.sh/)
- **音效引擎**：Web Audio API 原生电子合成器

## 🚀 本地开发与启动

### 环境准备
- [Node.js](https://nodejs.org/) (v18+) 或 [Bun](https://bun.sh/) (推荐)

### 安装依赖并启动
```sh
# 1. 安装依赖
bun install   # 或 npm install

# 2. 启动开发服务器
bun run dev   # 或 npm run dev

# 3. 生产环境构建测试
bun run build # 或 npm run build
```

浏览器访问 `http://localhost:3000` 即可开始体验复古电脑与 20 款卡带游戏！
